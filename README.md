## ✨ Возможности

- 🎤 Слова песни появляются в игровом мире в такт музыке
- 🏝️ «Остров» сверху с названием трека; пока открыто любое меню, он раскрывается в плеер (время, shuffle, назад, пауза, вперёд, repeat)
- 🎧 Автоматически видит, что играет в **Spotify** (и других плеерах через системное управление медиа), и подхватывает трек
- 🌐 Тексты с таймингами ищутся сами на нескольких сайтах по очереди: **LRCLIB → NetEase → QQ Music → Kugou → Kuwo**. Каждый сайт можно выключить во вкладке **More**
- 📄 Если синхронного текста нигде нет, берётся обычный текст (LRCLIB / lyrics.ovh), а тайминг распределяется по длине песни. Переключатель **Unsynced fallback**
- 🎨 **22 цветовые темы**, свой цвет через RGB-ползунки или **HEX-поле**, «Случайная тема», обмен цветов текста и свечения
- 🌈 **13 режимов цвета букв (Shimmer)**: Off, Glint, Rainbow, Flow, Pulse, Aurora, Fire, Flicker, Gradient, Sunset, Ocean, Candy, Matrix
- 🔤 **20 шрифтов** (с кириллицей), страницы в меню; **Bold / Italic / Underline**, регистр **UPPER / lower**
- ✨ 16 эффектов появления и исчезновения: Fade, Rise, Scale In/Out, Slide Left/Right, Pop, Float, Rotate, Blur, Glitch, Type, Wave, Drop, Decode, Fall. Кнопки «Random effects» и «Swap in / out»
- 👁️ Слова появляются в поле зрения (в том числе в третьем лице), не заходят в блоки
- ⚙️ Меню на правом `Shift`: вкладки **Text · Theme · Anim · Font · Music · Now · More**
- 🔑 Горячие клавиши: вкл/выкл текст, сдвиг синхронизации ±0.1 с, следующая тема, найти текст заново (не назначены, задаются в Управлении → «Плеер»)
- 💬 Команды `/stolaslyrics` (см. ниже), в том числе `search`, `fetch`, `theme`, `offset`
- 📂 Положи `Исполнитель - Название.lrc` в папку `songs`, и он станет песней после «Reload songs»
- 🖥️ Только клиентский мод: на сервер ставить не нужно

## 🎨 Меню: что где

| Вкладка | Что внутри |
| --- | --- |
| **Text** | Lyrics вкл/выкл, Layout, Size, Distance, Spread, Opacity, Sync offset, Through walls, **Text shadow**, **Hide if paused**, **Max lines** (1-8), **Anim speed** |
| **Theme** | Тема (показывает текущую или `Custom`), Random theme, RGB-ползунки текста и свечения, **HEX-поля** (`#RRGGBB`), Neon, Glow, Blur, Swap colors |
| **Anim** | In / Out effect, Effects from (Menu / File / Mix), Shimmer, Shimmer speed, Glint brightness, Tilt, Random effects, Swap in/out |
| **Font** | Шрифты по страницам (каждый показан своим шрифтом), Bold, Italic, Underline, Letters (As is / UPPER / lower) |
| **Music** | Source, Reload songs, Prev / Play / Next, Time, Island, Island scroll, Island lyrics, Console line, Side preview, Auto lyrics |
| **Now** | Предыдущая, текущая и следующая песни |
| **More** | **UI accent** и **UI background** (цвета меню и острова), Island opacity / height, Side text size, **Words / piece**, Rebuild songs, Unsynced fallback, переключатели сайтов, Hotkey messages |

### Что исправлено в темах
- Кнопка пресета показывала *следующий* пресет, а не текущий, и считала от устаревшего номера. Теперь она показывает текущую тему (или `Custom`, если цвета свои) и переключает на следующую.
- Цвет меню, острова и строки статуса брался прямо из «Glow color»: тёмное свечение (чёрный, тёмно-синий) делало интерфейс почти невидимым. Теперь акцент интерфейса автоматически осветляется до читаемого, а во вкладке **More** его можно зафиксировать отдельным цветом.
- Список шрифтов обрезался на 12 штуках. Теперь есть страницы.
- HEX-цвет, о котором раньше говорилось в README, в коде отсутствовал. Теперь это настоящие поля во вкладке **Theme**.
- Парсер LRC неправильно читал строки с несколькими таймкодами (`[00:10.00][00:50.00]текст`), заголовок `[offset:...]` и словесные теги `<00:10.50>`.

### Свои шрифты
Шрифты лежат в `assets/evolyrics/font/` внутри jar. Чтобы добавить или заменить шрифт, сделай ресурспак: положи `имя.ttf` и `имя.json` (по образцу любого `.json` рядом) в `assets/evolyrics/font/`, включи пакет в игре. Новый шрифт сам появится в меню. Выбирай шрифты с кириллицей, если песни на русском.

## 📦 Шаг 1. Установка мода

1. Установи **Forge 1.20.1** (47.4.23 или новее).
2. Скачай `stolaslyrix.jar` и положи в папку `.minecraft/mods`.
3. *(по желанию)* Шрифт `StolasLyrics-font.zip` положи в `.minecraft/resourcepacks` и включи в игре: **Настройки → Наборы ресурсов**. Он меняет шрифт во всей игре.
4. Запусти игру.

## 🌉 Шаг 2. Bridge (связь со Spotify)

Сам мод не видит Spotify. Для этого есть маленькая программа **bridge**: она смотрит, какая песня играет, сама скачивает текст и передаёт всё в мод.

### Установка (один раз)

1. Установи **Python 3.12** с [python.org](https://www.python.org/downloads/). В первом окне установщика обязательно поставь галочку **Add python.exe to PATH**.
2. Открой **cmd** (`Win + R`, впиши `cmd`, Enter) и выполни:

   ```bash
   pip install winsdk
   ```

3. Скачай файл [`bridge/bridge.py`](bridge/bridge.py): открой его на GitHub и нажми кнопку **Download raw file** (иконка со стрелкой вниз справа над кодом). Положи его куда удобно, например в `Загрузки`.

### Запуск

В cmd выполни (путь поменяй на свой):

```bash
python C:\Users\ТВОЁ_ИМЯ\Downloads\bridge.py
```

Откроется панель с логотипом STOLAS:

## 🎮 Шаг 3. Играем

1. Запусти bridge и включи любую песню в **Spotify**. В журнале панели появится `Текст скачан ...`.
2. Запусти Minecraft (Forge 1.20.1) и зайди в мир.
3. Нажми **правый Shift** → **Source: Bridge** → **Reload songs**.
4. Слова полетят вокруг тебя в такт песне, а сверху появится остров с названием.

> При **каждой новой песне** текст скачивается сам, но в игре нужно один раз нажать **Reload songs**.

### Если что-то не так

| Проблема | Что делать |
|----------|------------|
| `Текст не найден` | Песни нет ни на одном сайте. Попробуй `/stolaslyrics search Исполнитель - Название`, положи `.lrc` в папку `songs` или добавь текст вручную |
| Слова идут не в такт | В меню подвинь слайдер **Sync offset** |
| `python` не найден | Переустанови Python и поставь галочку **Add python.exe to PATH** |
| Spotify «не найден» в панели | Запусти приложение Spotify (не браузерную версию) и включи песню |
| Другая папка Minecraft (свой лаунчер) | В начале `bridge.py` поменяй `CONFIG_DIR` |

Журнал работы лежит в `%APPDATA%\.minecraft\config\evolyrics\bridge.log`.

## 📁 Где что лежит

Всё хранится в `%APPDATA%\.minecraft\config\evolyrics\`:

| Файл | Что это |
|------|---------|
| `bridge.json` | текущий трек и позиция |
| `settings.json` | настройки мода |
| `songs/<Исполнитель - Название>/lyrics.json` | тексты песен |
| `bridge.log` | журнал bridge |

## 🎹 Управление

| Клавиша | Действие |
|---------|----------|
| правый `Shift` | Открыть меню плеера (повторное нажатие закрывает) |
| не назначены | Следующая / предыдущая песня, пауза, **текст вкл/выкл**, **сдвиг синхронизации ±0.1 с**, **следующая тема**, **найти текст заново**. Назначаются в Управлении, категория «Плеер» |

## 💬 Команды

Основная команда: `/stolaslyrics`

| Команда | Описание |
|---------|----------|
| `/stolaslyrics list` | список загруженных песен |
| `/stolaslyrics reload` | перечитать песни с диска |
| `/stolaslyrics play <песня>` | включить песню |
| `/stolaslyrics pause` | пауза |
| `/stolaslyrics resume` | продолжить |
| `/stolaslyrics stop` | остановить |
| `/stolaslyrics seek <секунды>` | перемотать |
| `/stolaslyrics add <эффект> <текст>` | добавить строку в активную песню на текущей секунде |
| `/stolaslyrics fetch` | найти текст для текущей песни заново |
| `/stolaslyrics search <Исполнитель - Название>` | найти текст по названию, сохранить и включить песню |
| `/stolaslyrics offset [секунды]` | показать или задать сдвиг синхронизации (-3 … 3) |
| `/stolaslyrics theme [название]` | список тем или выбрать тему |
| `/stolaslyrics font <название>` | выбрать шрифт |
| `/stolaslyrics toggle` | включить / выключить текст |
| `/stolaslyrics sources` | какие сайты текстов включены |
| `/stolaslyrics rechunk` | пересобрать сохранённые песни с новым «Words / piece» |
| `/stolaslyrics info` | сведения о текущей песне |
| `/stolaslyrics reset` | сбросить настройки |

## 📝 Свои тексты

Каждая песня это папка `songs/<Исполнитель - Название>/` с файлом `lyrics.json`:

```json
{
  "title": "Название",
  "artist": "Исполнитель",
  "lyrics": [
    { "time": 12.5, "text": "первые слова", "effect": "FADE", "out": "FADE", "duration": 2.0 }
  ]
}
```

## Управление плеером в меню

На вкладке **Music**: кнопки **Prev / Pause-Play / Next**, ползунок **Time** (перемотка) и тумблеры острова. На вкладке **Songs** список песен (по 8 на странице), клик запускает песню и переключает Source на Manual.

- Если включён встроенный мост (Source: Bridge), кнопки и перемотка управляют настоящим плеером (Windows: системное управление медиа). Перемотка работает не во всех плеерах: если плеер её не принимает, ползунок вернётся на реальную позицию.
- Отдельные клавиши для «следующая», «предыдущая» и «пауза» можно назначить в Настройки → Управление → Плеер.
