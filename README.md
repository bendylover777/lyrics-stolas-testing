## ✨ Возможности

- 🎤 Слова песни появляются в игровом мире в такт музыке
- 🏝️ «Остров» сверху с названием трека
- 🎧 Автоматически видит, что играет в **Spotify**, и подхватывает трек
- 🌐 Тексты с таймингами скачиваются сами с [LRCLIB](https://lrclib.net) (ключи не нужны)
- 🎨 Эффекты появления: `fade` · `rise` · `scale_in` · `slide_left` · `slide_right` · `pop` · `float` · `rotate` · `drop` · `bounce` · `wave` · `shake` · `glitch` · `typewriter`
- 🎨 Настраиваемый **цвет** слов и свечения (10 пресетов, радуга и свой HEX)
- 🔤 **8 шрифтов** на выбор прямо в меню (только для lyrics)
- 👁️ Режим **«Keep in view»**: слова появляются в поле зрения, в том числе в **третьем лице**
- 🌈 **Неоновый перелив** цвета, **блик (glint)** по словам и **превью** следующей строки
- 📟 **Строка статуса** в игре (мост, играет/пауза, найден ли текст), включается и выключается в меню
- ⚙️ Меню настроек в игре (клавиша `K`)
- 🖥️ Только клиентский мод: на сервер ставить не нужно

## 🎨 Цвет, шрифты и вид текста

Всё настраивается в меню на **`K`**. В меню две страницы: **Main options** и **Style & effects**. Переключатель страниц — кнопка внизу слева.

Страница **Style & effects**:

| Пункт меню | Что делает |
| --- | --- |
| **Text color** | цвет слов: White, Blue, Purple, Pink, Red, Orange, Yellow, Green, Cyan, Rainbow |
| **Glow color** | цвет свечения вокруг слов (те же пресеты) |
| **Font** | шрифт: Default, Sans, Serif, Mono, Soft, Wide, Italic, Unifont |
| **Shadow** | тень под текстом |
| **Neon flow / Neon speed** | цвет слов плавно перетекает между Text color и Glow color. С Glow color = Rainbow получается радужный перелив |
| **Glint** | белый блик, пробегающий по словам (0 = выключен) |
| **Preview next line** | следующая строка слегка просвечивает заранее, на своём месте сбоку |
| **Keep in view** | слова появляются в поле зрения перед тобой (1-е и 3-е лицо). Если выключить, они разлетаются вокруг игрока |
| **Size / Distance / Scatter** | размер, расстояние и разброс слов (страница Main options) |
| **Status line** | маленькая строка под островом: Bridge / Manual, Playing / Paused, сколько строк текста, время. Можно выключить |
| **In effect / Out effect** | анимация появления и исчезновения (теперь 15 штук, включая Drop, Bounce, Wave, Shake, Glitch, Typewriter) |
| **Glow / Blur / Opacity** | сила свечения, размытие, прозрачность |

### Свой цвет (HEX)
Открой `%APPDATA%\.minecraft\config\evolyrics\settings.json` и впиши, например:

```
"customTextColor": "#FF3D81",
"customGlowColor": "#7FA8FF"
```

Если поле не пустое, оно главнее пресета. Чтобы вернуть пресет, оставь `""`.

### Свой шрифт
Шрифты лежат в `assets/evolyrics/font/` внутри jar: `sans.ttf`, `serif.ttf`, `mono.ttf`, `soft.ttf`, `wide.ttf`, `italic.ttf`. Чтобы заменить любой из них своим, сделай ресурспак, положи в него файл с тем же именем по тому же пути (`assets/evolyrics/font/sans.ttf`) и включи пакет в игре. Выбирай шрифты с кириллицей, если песни на русском. `Unifont` подходит для китайского, японского и корейского.

## 📦 Шаг 1. Установка мода

1. Установи **Forge 1.20.1** (47.4.23 или новее).
2. Скачай `StolasLyrics-1.0.0.jar` и положи в папку `.minecraft/mods`.
3. *(по желанию)* Шрифт `StolasLyrics-font.zip` положи в `.minecraft/resourcepacks` и включи в игре: **Настройки → Наборы ресурсов**. Он меняет шрифт во всей игре.
4. Запусти игру.

## 🌉 Шаг 2. Bridge (связь со Spotify)

Сам мод не видит Spotify. Для этого есть маленькая программа **bridge**: она смотрит, какая песня играет, сама скачивает текст и передаёт всё в мод.

### Установка (один раз)

1. Установи **Python 3.12** с [python.org](https://www.python.org/downloads/). В первом окне установщика обязательно поставь галочку **Add python.exe to PATH**.
2. Открой **cmd** (`Win + R`, впиши `cmd`, Enter) и выполни:

   ```bash
   pip install winsdk
   ```

3. Скачай файл [`bridge/bridge.py`](bridge/bridge.py): открой его на GitHub и нажми кнопку **Download raw file** (иконка со стрелкой вниз справа над кодом). Положи его куда удобно, например в `Загрузки`.

### Запуск

В cmd выполни (путь поменяй на свой):

```bash
python C:\Users\ТВОЁ_ИМЯ\Downloads\bridge.py
```

Откроется панель с логотипом STOLAS:

## 🎮 Шаг 3. Играем

1. Запусти bridge и включи любую песню в **Spotify**. В журнале панели появится `Текст скачан ...`.
2. Запусти Minecraft (Forge 1.20.1) и зайди в мир.
3. Нажми **`K`** → **Source: Bridge** → **Reload songs**.
4. Слова полетят вокруг тебя в такт песне, а сверху появится остров с названием.

> При **каждой новой песне** текст скачивается сам, но в игре нужно один раз нажать **Reload songs**.

### Если что-то не так

| Проблема | Что делать |
|----------|------------|
| `Текст не найден` | Этой песни нет в LRCLIB. Будет только остров, а текст можно добавить вручную |
| Слова идут не в такт | В меню `K` подвинь слайдер **Sync offset** |
| `python` не найден | Переустанови Python и поставь галочку **Add python.exe to PATH** |
| Spotify «не найден» в панели | Запусти приложение Spotify (не браузерную версию) и включи песню |
| Другая папка Minecraft (свой лаунчер) | В начале `bridge.py` поменяй `CONFIG_DIR` |

Журнал работы лежит в `%APPDATA%\.minecraft\config\evolyrics\bridge.log`.

## 📁 Где что лежит

Всё хранится в `%APPDATA%\.minecraft\config\evolyrics\`:

| Файл | Что это |
|------|---------|
| `bridge.json` | текущий трек и позиция |
| `settings.json` | настройки мода |
| `songs/<Исполнитель - Название>/lyrics.json` | тексты песен |
| `bridge.log` | журнал bridge |

## 💬 Команды

Основная команда: `/stolaslyrics`

| Команда | Описание |
|---------|----------|
| `/stolaslyrics list` | список загруженных песен |
| `/stolaslyrics reload` | перечитать песни с диска |
| `/stolaslyrics play <песня>` | включить песню |
| `/stolaslyrics pause` | пауза |
| `/stolaslyrics resume` | продолжить |
| `/stolaslyrics stop` | остановить |
| `/stolaslyrics seek <секунды>` | перемотать |
| `/stolaslyrics add <эффект> <текст>` | добавить строку в активную песню на текущей секунде |

## 📝 Свои тексты

Каждая песня это папка `songs/<Исполнитель - Название>/` с файлом `lyrics.json`:

```json
{
  "title": "Название",
  "artist": "Исполнитель",
  "lyrics": [
    { "time": 12.5, "text": "первые слова", "effect": "FADE", "out": "FADE", "duration": 2.0 }
  ]
}
```
